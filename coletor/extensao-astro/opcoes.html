Vortex · Vagas

Esta extensão é do dono da Vortex. Ela lê a aba Vagas da companhia no PilOps (carga e passageiros de cada vaga, que só o dono vê) e publica no planejador, para todos os pilotos verem quanto cada vaga tem.

Token do GitHub

Cole aqui o token de acesso fino (fine-grained) que dá acesso só ao repositório vortexairways/vortex-planejador, com a permissão Contents: Read and write. Ele fica guardado só neste Chrome.

Sincronizar

Use o botão Sincronizar vagas no planejador da Vortex ou o botão abaixo. Deixe o PilOps logado neste Chrome; a extensão abre a aba Vagas em segundo plano, lê e fecha.

Amostra da leitura

O código HTML da primeira vaga com números, para conferir o formato das barras caso algo saia errado. Não é publicado.
